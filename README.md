## Current interests & projects

### DentoFlow / DentStock
A dental-practice digital workflow project focused on connecting:

**appointments → patients → procedures → material consumption → real costs → stock → purchasing**

with the goal of making dental practice management more accurate, practical and data-driven.

### Dental simulation & continuing education
Exploring modern training models combining:

**digital learning → VR/haptic simulation → practical simulation → competency-based assessment**

for dentists, dental technicians and other oral-health professionals.

### Teaching
